## What is claimed / not claimed

**Claims.** The governance object is the rate ratio \(G = R_d / R_p\) and the stock \(S\) of known-but-unpatched exploitable ambiguities (\(dS/dt = R_d - R_p\)). Discovery and execution are different governance problems. Three actor classes (corporate optimizer, state actor, misaligned agent) need different defenses. Defenses written as open-textured rules re-enter the same search.

**Non-claims.** \(G\) is a definition, not a fitted dynamical model. Regime magnitudes in §4.4 are heuristics, not measurements. SocioHack (Liu et al., 2026) is a sandbox preprint without independent replication. Rice / FLP / attestation in §6.4 are analogical, not a proof that courts instantiate those models. The reward↔regulation isomorphism is a working hypothesis.
