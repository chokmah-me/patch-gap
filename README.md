> Legal open texture was always exploitable; the bound was work factor. AI collapses discovery cost while repair stays on a legislative/judicial clock. This repository is the **paper source and PDF**, not a software deposit.

Paper (v1.0): [The Governance Patch-Gap: Machine-Speed Exploit Discovery Against Human-Speed Legal Repair](https://zenodo.org/records/21910875)

## What is claimed / not claimed

**Claims.** The governance object is the rate ratio \(G = R_d / R_p\) and the stock \(S\) of known-but-unpatched exploitable ambiguities (\(dS/dt = R_d - R_p\)). Discovery and execution are different governance problems. Three actor classes (corporate optimizer, state actor, misaligned agent) need different defenses. Defenses written as open-textured rules re-enter the same search.

**Non-claims.** \(G\) is a definition, not a fitted dynamical model. Regime magnitudes in §4.4 are heuristics, not measurements. SocioHack (Liu et al., 2026) is an unreplicated sandbox preprint. Rice / FLP / attestation in §6.4 are analogical, not a proof that courts instantiate those models. The reward↔regulation isomorphism is a working hypothesis.
